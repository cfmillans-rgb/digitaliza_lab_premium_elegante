Antes de elegir un estilo

Estos diseños sirven para imaginar cómo podría verse tu sitio. Esto es lo que conviene saber:

Son referencias, no clientes

Los creamos para mostrar estilos. Para ver sitios hechos para clientes, revisa los trabajos reales.

Tu sitio se hace a medida

Se construye con la información, los textos, las imágenes y las definiciones de tu negocio, no con los datos de una muestra.

Algunas funciones se cotizan aparte

Si una muestra tiene algo que no está en lo que incluye el Sitio Web Informativo, como un carro de compras, esa parte se cotiza como proyecto a medida.

¿Te gustó algún estilo?
